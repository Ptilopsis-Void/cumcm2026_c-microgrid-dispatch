# 微网与外部电网电力调控策略

这是我参加 2026 年高教社杯全国大学生数学建模竞赛 C 题时使用的代码。仓库按第一问到第四问整理，保留了建模程序、参数配置、主要结果、图表和最终提交文件。

## 主要思路

| 问题 | 主要内容 | 方法 |
| --- | --- | --- |
| 第一问 | 已知负荷与光伏预测下的单日购电和储能调度 | 连续线性规划、对偶价格分析、动态规划互证 |
| 第二问 | 预测存在误差时的全年日前购电策略 | 因果预测、历史残差情景、两阶段随机规划、DP 价值执行器 |
| 第三问 | 利用日内新增光伏预测滚动调整购电计划 | 滚动时域优化、节点更新、消融与敏感性分析 |
| 第四问 | 加入实时电价预测后的购电与储能调度 | 价格预测、联合情景、4-2/4-3 两类调度策略 |

所有问题均采用 10 分钟时间步长。储能额定容量为 12000 kWh，允许工作范围为 1200～10800 kWh，充放电效率均为 0.9，最大充放电功率为 5000 kW。

每一问的 `代码` 目录中，带编号的脚本按执行顺序排列；以下划线开头的文件是公共函数或策略模块。`模型结果`、`模型结果图` 和 `报告` 中保存的是本次计算得到的主要结果，`提交结果` 中保存题目要求的 Excel 文件。

## 运行环境

建议使用 Python 3.11。主要依赖为 NumPy、SciPy、pandas、openpyxl 和 Matplotlib，线性规划由 SciPy 自带的 HiGHS 求解器完成，不需要商业求解器。

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## 运行方法

下面的命令均在仓库根目录执行。

### 第一问

```bash
python "第一问最终版/代码/24_运行最终版完整流程.py"
```

### 第二问

第二问按编号依次运行 `01`～`10`，然后运行最终整理脚本：

```bash
python "第二问最终版/代码/17_最终定稿与交付.py"
python "第二问最终版/代码/19_生成结果总览.py"
```

其中 `12`～`16`、`18`、`30`、`31` 主要用于差异分析、收敛性检查和论文材料校验，可按需要单独运行。

### 第三问

```bash
python "第三问最终版/代码/12_运行第三问完整求解.py"
```

若只想检查执行步骤而不正式求解，可以加 `--dry-run`。敏感性与收敛性分析耗时较长，也可以通过 `--only` 选择需要运行的步骤。

### 第四问

```bash
python "第四问最终版/代码/13_一键完整构建.py --continue-on-fail"
```

第四问的 `09_对照消融与敏感性.py` 默认不在一键流程中重复执行；需要时可使用 `--only 09` 单独运行。

## 备注

- 电价单位为元/kWh，功率单位为 kW，单时段电量单位为 kWh。
- 时间标签按区间终点理解，每天共 144 个时段。
- 图中的中文字体会根据系统字体自动选择；缺少中文字体时不影响数值计算，但图中文字可能显示异常。
- 中间的 `.npz` 文件体积较大，未纳入仓库，可由前序脚本重新生成。
