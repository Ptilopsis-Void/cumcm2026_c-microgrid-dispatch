# 第一问 连续状态动态规划验证报告（第 3.3 节）

> 本报告基于后续时域 LP 构造最终连续 LP **同一模型**的
> 价值函数重构与 Bellman 一致性检验（而非并行的“第二套模型”）。不修改 LP/MILP/图2—图4/result1.xlsx，
> F_1 与轨迹首步仍由 LP 求得，不是独立 DP 求解器。

## 1. 连续 DP 数值实现方法

采用“**后续时域 LP 价值查询 + 自适应分段线性重构**”
（不采用粗糙固定 SOC 网格）：
1. 给定 (t,e)，构造 t..T 的后续时域 LP，固定进入状态 E_{t-1}=e，精确施加终端 E_T=6000 kWh；
2. 返回最小费用 F_t(e) 作为价值函数查询；
3. 在有效状态域 I_t 内用中点细分自适应增加采样点，当相邻区间斜率变化或线性插值
   误差超过容差（1e-6 元）时继续细分，直到最小子区间宽度 1e-4 kWh；
4. 保存折点、线段斜率与值函数数据。该数值工具仅用于计算与验证 Bellman 递推（式10—14），
   论文理论主体仍是式（10）—（14）的 Bellman 递推。

## 2. 是否使用固定网格

否。采用自适应分段线性重构，最小子区间宽度 1e-4 kWh，线性残差容差 1e-6 元。
等价于在“斜率变化位置”附近自动加密、在纯线性区自动保持稀疏。

## 4. 整日 LP 与后续时域 LP 费用一致性

F_1(6000) = 35126.9485892896 元；锁定 LP 最优值 J_1 = 35126.9485892896 元；
绝对误差 = 2.910e-11 元 ≤ 1e-5，满足本文设置的数值容差。

后续 LP 首步恢复轨迹总购电量 = 59482.6989983539 kWh；锁定 LP 总购电量 = 59482.6989983539 kWh；
误差 = 7.276e-12 kWh；轨迹费用 Σc_t g_t = 35126.94858929 元。

## 5. Bellman 递推验证

对代表时刻 0:00、6:00、12:00、18:00、临近24:00，从有效域选取左端点、中间状态、右端点
与自适应折点，验证 Bellman 等式最大残差：
- 最大残差 = 3.898e-06 元（发生于 t=73(12:00), e=7901.123214），容差 1e-3。

## 6. 凸性与边际价值单调性

对相邻采样状态计算割线斜率 s_i，验证 s_{i+1}≥s_i−ε：
- 最大凸性违例 = 5.086e-08 元/kWh（发生于 t=37(6:00), e∈[9422.871208,9422.871351]→[9422.871351,9422.871423]），容差 1e-3；
- 边际价值 λ_t(e)=−∂F_t(e)，λ 非增 ⟺ 割线斜率不减，结论同源成立。

## 7. 终端可达性与可达状态域

- 终端条件精确执行：E_144 = 6000.0000000000 kWh（误差 0.000e+00 kWh），严格等于 6000；
- 可达状态域 I_t 始终在 [1200,10800] 内，且随临近终点单调收缩；
- I_{T+1} = [6000.000000, 6000.000000] = {6000}（精确单点）。

## 9. 命题 3.1 简化口径

后续时域LP右端关于初始状态e仿射，最优值是仿射函数族的上确界，因此在有效域上凸且分段线性。凸函数的次梯度单调不减，故负次梯度表示的边际价值单调不增。数值采样用于一致性检查：
1. F_t(e) 在 I_t 上是凸分段线性函数（割线斜率单调不减，最大违例 5.086e-08）；
2. 边际价值 λ_t(e)∈−∂F_t(e) 随 e 增加单调不增；
3. 即储能量越充足，再增加一单位储能所节约的未来购电费用越低。
