# 第一问最终模型数据接口

> 状态：最终主模型为**连续线性规划（LP）**。本接口用于最终LP完整流程，包含求解、对偶分析与Bellman一致性检验。
> 含二进制变量的 MILP 已冻结为历史基准（互证数据见 `模型结果/最终LP与历史MILP互证.csv`），仅用于数值互证。

## 1. 最终模型使用能量变量
最终连续 LP 的决策变量与参数均为**每个 10 分钟时段的交流侧电量（kWh）**，不再以功率（kW）直接作为决策变量。

## 2. 功率乘 1/6 转换为每时段电量
每个时段时长 Δt = 1/6 小时（10 分钟），电量（kWh）= 功率（kW）× Δt（h）。

## 3. 正式输入字段与数学符号对应关系

| 正式输入字段 | 数学符号 | 含义 | 单位 |
|---|---|---|---|
| interval_index | — | 时段编号 1..144 | 无 |
| original_time_label | — | 10 分钟区间终点标签（溯源） | 无 |
| interval_start | — | 区间起点 HH:MM | 无 |
| interval_end | — | 区间终点 HH:MM | 无 |
| delta_hours | Δt | 每时段时长 1/6 | 小时 |
| price_yuan_per_kwh | c_t | 交易电价 | 元/kWh |
| load_energy_kwh | L_t | 负荷电量 | kWh |
| pv_forecast_energy_kwh | V_t | 光伏预测电量 | kWh |

校验关系：`load_energy_kwh = load_kw × Δt`，`pv_forecast_energy_kwh = pv_forecast_kw × Δt`，其中 Δt = 1/6。
这两个电量字段的**数值不变**，仅用途由“描述性统计”调整为“模型正式输入”。

## 4. 最终决策变量及单位

| 变量 | 含义 | 单位 |
|---|---|---|
| g_t | 时段计划购电量 | kWh |
| C_t | 交流侧充电量 | kWh |
| D_t | 交流侧放电量 | kWh |
| U_t | 未利用供能（非负供需松弛量） | kWh |
| E_t | 电池内部储电量 | kWh |

## 5. 输出功率时除以 1/6

| 功率输出 | 公式 |
|---|---|
| 电网购电功率 | grid_purchase_power_kw = g_t / Δt |
| 充电功率 | charge_power_kw = C_t / Δt |
| 放电功率 | discharge_power_kw = D_t / Δt |
| 弃光功率 | curtailment_power_kw = U_t / Δt |

## 6. 允许电网充电
`operation.allow_grid_charging = true`。

## 7. 禁止电网售电
`operation.allow_grid_export = false`。

## 8. 允许未利用光伏（弃光）
`operation.allow_pv_curtailment = true`。

## 9. 最终 LP 不包含二进制变量
`operation.binary_charge_state_required = false`，最终 LP 不设置充放电互斥的 0-1 变量 z_t。

## 10. 历史 MILP 仅用于数值互证
含二进制变量 z_t 的 MILP 已冻结为历史基准，仅用于验证最终连续 LP 结果（数值互证），不是最终主模型。
