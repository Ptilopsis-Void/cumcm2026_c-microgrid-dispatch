# 第一问 内部价格与储能充放电阈值分析（第 3.2 节）

> 本报告严格按“第一问最终流程”第 3.2 节顺序编写，仅提取并验证对偶影子价格，

## 1. 供需平衡对偶变量 π_t

供需平衡方程为

　　L_t + C_t + U_t − g_t − V_t − D_t = 0，

对应拉格朗日项 π_t(L_t+C_t+U_t−g_t−V_t−D_t)。在当前约束方向与 SciPy/HiGHS 符号约定下，
`raw_marginal = ∂(最优目标)/∂b_eq = −μ`，μ 为乘子，故 π_t = −raw_marginal_balance。
经式(9)双侧 KKT 判定：π 取 `-raw` 时违例为 0.00e+00，取 `+raw` 时违例为 1.75e+03，
故 π_t = -raw_marginal。

π_t ∈ [0.371300, 1.256100] 元/kWh。

## 2. 储能状态对偶变量 λ_t

储能递推方程为

　　E_t − E_{t−1} − ηC_t + D_t/η = 0（η=0.9），

对应拉格朗日项 λ_t(E_t−E_{t−1}−ηC_t+D_t/η)。同样 λ_t = −raw_marginal_storage。
经充放电约化成本 KKT 判定：λ 取 `-raw` 时违例为 1.11e-16，取 `+raw` 时违例为 2.51e+00，
故 λ_t = -raw_marginal。

λ_t ∈ [0.471111, 1.130490] 元/kWh。

## 3. 式（9）互补关系

0 ≤ π_t ≤ c_t，g_t(c_t−π_t)=0，π_t·U_t=0。

- π 下界违例（π_t<0 的最大越过量）：0.000e+00 元/kWh
- π 上界违例（π_t>c_t 的最大越过量）：0.000e+00 元/kWh
- 购电互补残差 g_t(c_t−π_t) 最大绝对值：0.000e+00 元（归一化 0.000e+00）
- 弃光互补残差 π_t·U_t 最大绝对值：0.000e+00 元（归一化 0.000e+00）

## 4. 正购电时 π_t = c_t

正购电时段数 86 段；其中 π_t 与 c_t 的最大误差 0.000e+00 元/kWh。

## 5. 未利用供能时 π_t = 0

未利用光伏（弃光）时段数 0 段；其中 π_t 偏离 0 的最大误差 0.000e+00 元/kWh。

## 6. 充电约化成本 π_t − ηλ_t

充电约化成本为 π_t − ηλ_t：消耗 1 kWh 交流侧电量用于充电的净机会成本。
0<C_t<S 时约化成本为 0；C_t=0 时非负；C_t=S 时非正。

## 7. 放电约化成本 −π_t + λ_t/η

放电约化成本为 −π_t + λ_t/η：放电 1 kWh 交流侧电量的净机会成本（含效率折算）。
0<D_t<S 时约化成本为 0；D_t=0 时非负；D_t=S 时非正。

## 8. 充电、静置与放电阈值

充电阈值 ηλ_t，放电阈值 λ_t/η。

- 若 π_t < ηλ_t：消耗 1 kWh 交流侧电量用于充电的当前机会成本低于折算后的储能价值，充电达到上限 C_t=S；
- 若 π_t > λ_t/η：当前内部价格高于保留能量的效率折算价值，放电达到上限 D_t=S；
- 若 ηλ_t < π_t < λ_t/η：两项约化成本均为正，C_t=D_t=0。
等号 π_t=ηλ_t 或 π_t=λ_t/η 成立时，相应动作约化成本为零，允许非零充电或放电；SOC 边界通过状态乘子影响 λ_t。

## 9. 往返效率 0.81 与跨时段套利条件

完整充放一次，位移 1 单位交流侧电量最终可向负荷交付 η²=0.81 单位交流侧电量。
从低价时段 a 向高价时段 b 转移电量有经济价值的基本条件为 η²c_b > c_a，即 0.81c_b > c_a。

- 前期充电时段（夜充最低购电价）：区间 2，c_a=0.4245 元/kWh
- 后期放电时段（最高放电价）：区间 124，c_b=1.3952 元/kWh
- 0.81·c_b − c_a = 0.705612 元/kWh > 0，满足套利条件。

| 内部价格 π_t | 0.4785 元/kWh |

| 放电阈值 λ_t/η | 0.5907 元/kWh |
| 购电量 g_t | 0.000000 kWh |
| 充电量 C_t | 116.983583 kWh（interior） |
| 放电量 D_t | 0.000000 kWh |
| 未利用光伏 U_t | 0.000000 kWh |

该时段外网电价为 0.9919 元/kWh，但内部价格仅 0.4785 元/kWh，显著低于外网电价。
原因是光伏除满足负荷外还有余量（正用于给储能充电，g_t=0 无需外购），
新增 1 kWh 需求的边际供给来自光伏而非外网，其机会成本由充电阈值决定，
故内部充电处于内部点 π_t=ηλ_t=0.4785，仍倾向于充电。
与图片“光伏供给使内部价格低于外网电价，因此仍可能充电”的解释一致。

## 附：对偶多解检查

LP 原始最优值唯一不代表对偶变量逐点唯一。分别用 HiGHS 默认、双单纯形、内点法重解同一 LP，
不改目标与约束，比较 π、λ 与目标值：

- 目标值最大差异：0.000e+00 元
- π 最大差异：0.000e+00 元/kWh
- λ 最大差异：1.639e-01 元/kWh（差异时段 11 个，其中静置时段 11 个 / 全部静置时段 62 个）

结论：本次三种算法所得 π 最大差 0.00e+00，λ 在 11 个时段存在不同取值（其中 11 个为静置时段 C=0 且 D=0，占全部 62 个静置时段的一部分）。不同对偶解均满足 KKT 条件并对应相同原始最优值；图片展示其中一组有效影子价格。
