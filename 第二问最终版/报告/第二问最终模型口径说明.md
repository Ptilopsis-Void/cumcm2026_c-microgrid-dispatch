# 第二问最终模型口径说明

> 本文件固化第二问最终采用的数学模型口径，作为正式交付的**单一事实来源**。
> 对应机器可读锁文件 `配置/第二问最终模型口径.yaml`。任何代码、报告与本文矛盾处，一律以本文为准。

## 1. 时间步长与标签

| 项 | 口径 |
| --- | --- |
| 时间步长 | $\Delta t = 1/6$ 小时，每天 $144$ 个 $10$ 分钟时段 |
| 标签含义 | 附件标签为**区间终点** |
| 示例 | `0:10` ↔ $[0{:}00, 0{:}10)$；`10:10` ↔ $[10{:}00, 10{:}10)$；`0:00+1` ↔ $[23{:}50, 24{:}00)$ |

## 2. 评分期

2025-02-01 至 2025-12-31，共 **334 天**（2025-01-01 … 01-31 为 31 天预热期，不计入评分）。

## 3. 预测（全部因果，无前视）

**主档（正式交付口径）= PDF 式（17a–17c）分解预测 + 3 日光伏回望**。
两档可由环境变量一键重现：`Q2_PREDICTOR`（`decomp` 默认 / `naive`）与 `Q2_PV_WINDOW`（光伏回望天数）。

### 3.1 负荷：日电量水平 × 日内形状（式 17a–17c）

| 项 | 口径 |
| --- | --- |
| 日类型 $k_d$ | 用 2025-01-01 … 01-14 的**平均日电量**识别**两个低负载星期**（本数据为**周五、周六**，$k_d=0$；其余 $k_d=1$）；**自 2025-01-15 起固定分类** |
| 日内形状 $\hat s_{d,t}$ | 式（17a）：$\hat s_{d,t} = \sum_{i\in I_d} L_{i,t} \big/ \sum_{i\in I_d} B_i$，$I_d$ 为**最近 3 个同类型历史日**，且 $\sum_t \hat s_{d,t}=1$ |
| 日电量水平 $\hat B_d$ | 式（17b）：$\hat B_d = B_{d-1}\exp\!\big[\beta_d\,(k_d-k_{d-1})\big]$，其中 $\beta_d = \operatorname{med}\limits_{i\in J_d}\dfrac{\ln(B_i/B_{i-1})}{k_i-k_{i-1}}$，$J_d$ 为**此前 35 天内的类型切换日** |
| 负荷预测 | 式（17c）：$\hat L_{d,t} = \hat B_d\,\hat s_{d,t}$ |
| 预热段 $d<14$（1/1–1/14） | 日类型尚未锁定，改用**同星期同期均值**；同星期样本少于 2 天时回退此前最多 7 天同期均值——这段预热残差保留其当时的信息边界 |

### 3.2 光伏（两档共用形式）

| 项 | 口径 |
| --- | --- |
| 光伏 $\hat V_{d,t}$ | 此前最多 **3** 天同期均值（主档） |
| 数学公式（日期序号 $d=1,\dots,365$） | $m_d=\min(3, d-1)$ |
| Python 实现（数组索引 $d_{\text{idx}}=0,\dots,364$） | `m = min(3, d_idx)` |

- 二者**严格等价**，因为 $d_{\text{idx}} = d - 1$（索引等价性已由单元测试验证，见 `模型结果/第二问_光伏回溯索引等价性验收.csv`）。
- 回望窗取 **3 天是由总费用择优**（3 日 1357.06 万元 < 7 日 1359.12 万元）；`Q2_PV_WINDOW=7` 即 7 日对照档。

### 3.3 朴素基线（仅用于消融对照，不进入主结果）

`Q2_PREDICTOR=naive` 时：负荷全程用**此前 35 天范围内同星期同期均值**（同星期历史样本少于 2 天时回退到此前最多 7 天同期均值），配 7 日光伏回望。
该档全套结果见 `朴素基线/`，年度总费用 $14\,024\,652.1254$ 元，作为论文的**消融对照**使用。

### 3.4 因果性

所有预测只使用当天 $0{:}00$ 以前的数据（无前视）。

## 4. 情景

- 残差库取**最近 30 个可用历史日**；
- 负载残差与光伏残差按**同一个历史日配对**（保留联合相关结构）；
- 生成 $M=30$ 个**等权**情景（$p_\omega=1/M$）；
- 情景重建只做**非负截断** $[\cdot]^+$；
- **不使用**历史 PV 最大值的额外截断。

## 5. 日前采购

采用图片式（20）—（23）的**两阶段情景 LP**：第一阶段共享计划 $g_t$，第二阶段情景相关变量 $b_{t,\omega}, C_{t,\omega}, U_{t,\omega}, D_{t,\omega}, E_{t,\omega}$。

## 6. 实际执行

最终采用「**各自重订计划 + DP 价值执行器**」方案：三个执行器（解析响应 / MPC / DP 价值执行器）各自维护真实储能状态、各自重订当天日前计划。

## 7. 跨日状态

- 每天日前 LP 的**初始库存 = 该执行器当天真实日初库存**；
- 实际**日末库存成为次日真实日初库存**（跨日连续，无日循环边界）。

## 8. 储能

| 参数 | 口径 |
| --- | --- |
| 容量 | $1200 \le E \le 10800$ kWh |
| 最大充/放电功率 | $5000$ kW |
| 单时段上限 | $S = 5000/6$ kWh |
| 充/放电效率 | $\eta_c = \eta_d = 0.9$ |

## 9. 费用

| 项 | 口径 |
| --- | --- |
| 计划购电 | 按 $c_t$ 全额收费 |
| 紧急购电 | 按 $5c_t$ 收费 |
| $\nu E_T$ | 仅为规划中的库存价值近似，**不进入实际账单** |

## 10. 运行限制

- **禁止**向外部电网售电；
- **允许**未利用供能（弃光等）；
- 实际执行时**不允许**用紧急购电主动给储能充电；
- 动作只使用**当前及此前**实际观测。

## 11. DP 实现

| 项 | 口径 |
| --- | --- |
| 正式程序网格 | $\delta = 6$ kWh 均匀网格近似 |
| 收敛验证 | $\delta = 3$、$1.5$ kWh 仅用于收敛验证 |
| 平坦最优区间 | 取**最大端点** |
