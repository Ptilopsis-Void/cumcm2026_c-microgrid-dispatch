## A-1　1 月桥接：不执行 1 月回测，1 月库存恒为 6000 kWh

## A-2　实时执行：用**当期实测**净负荷闭环（不是先验预测替代）

| 项 | 内容 |
|---|---|
| **假设** | 每个 10 min 时段的**实际执行**使用该时段的**实测净负荷**（= 当期实时观测量），并即时决定充/放/紧急购电/弃电，同时更新真实 SOC；下一时段的起点为**真实 SOC**（闭环），不使用预测值代替。 |
| **题面依据** | 题面要求「在每天 0:00 制定当天计划购电策略，在其他预报时刻制定**调整**购电策略」，并单独计算**紧急购电费用** —— 紧急购电的存在本身就意味着执行阶段观测到真实缺口后仍有补救动作，即执行是**逐时段闭环**的。 |
| **实现依据** | `代码/_cand_engine.py`：`N_act_seg = f["N_actual_all"][d, k0:k1]`（实测净负荷）→ `S7.dp_execute(R_seg, N_act_seg, q_seg, e_node)`（真实库存逐时段递推）。规划/比较层用情景集，执行层用**实测**，二者分离。 |
| **论文写法** | 「节点内按 10 min 时段闭环执行：每个时段以当期实测净负荷为输入，按价格阈值规则决定充放与紧急购电，并据此更新真实储电量；决策层（候选规划与接受检验）在情景集上评估，执行层使用实测序列，因此报告的结果是**含实时闭环**的实际费用。」 |

## A-3　充放效率各 90 %（往返 81 %）

| 项 | 内容 |
|---|---|
| **假设** | 充电效率 90 %、放电效率 90 %（`eta = 0.9`），**往返效率 81 %**。同段内 SOC 递推为 `ΔE = η·C − D/η`。 |
| **依据** | 配置 `eta: 0.9`（`配置/第三题_参数与口径.yaml`）。 |
| **⚠️ 常见误判** | 电池侧**单时段变化上界**因此是 `η·S = 750`（充）与 `S/η = 925.926`（放），**不是** `S = 833.333`。若按 `|ΔE| ≤ S` 判定会误报「越界」（925.926 > 833.333）。验证套件 `C3·*` 已按正确口径判定并通过。 |
| **论文写法** | 「充、放效率各取 90 %（往返 81 %）；储能侧单时段电量变化上界对应 750 kWh（充）/ 925.926 kWh（放）。」 |

| 项 | 内容 |
|---|---|
| **假设** | ① 时间轴按 **10 min** 离散（144 段/日）；② 附件 3 的**整点小时**预报按「**小时内恒定**」展开到 10 min 格点。 |
| **依据** | 附件 1（典型日）与附件 2 均为 **365×144**，可**推断**步长为 24 h/144 = 10 min；附件 3 预报为「预报 1 小时 … 预报 24 小时」的整点小时量。 |
| **⚠️ 必须如实披露** | 这两条是**本文选定的离散化约定**，**不能由附件的列名唯一证明**（列名未声明步长，也未声明小时内的分配方式）。不同的展开方式（如线性插值、均匀分配）会改变逐时段结果，**且不保证**逐时段预报的小时/日/年**积分值**与本文相同。物理账本的能量守恒（`Q + b + D − C − N − 弃电 = 0`）在任何展开方式下都成立，但那是**结算口径的恒等式**，不能用来论证「不同离散化等价」。 |

## A-5　B 合同：相对**零点计划量**、按**最终兑现货量****一次性**结算

| 项 | 内容 |
|---|---|
| **假设（本文读法）** | 全天只结算**一次**：以 0:00 计划量 $P$ 为基准，按**最终兑现货量** $Q$ 结算：<br>$$\text{费用}=\sum_t c_t\min(P_t,Q_t)+0.5\sum_t c_t(P_t-Q_t)^{+}+1.5\sum_t c_t(Q_t-P_t)^{+}+5\sum_t c_t b_t$$<br>即：基准部分按实际兑现量 $\min(P,Q)$ 以电价 $c$ 计；**未兑现**部分按 $0.5c$ 计违约费；**超出**部分按 $1.5c$ 计加价费；另计紧急购电费（$5c$）。 |
| **题面依据** | 「计划购电量**高于调整购电量的部分**，违约电价是交易时刻电价的 50 %；调整购电量**高于计划购电量的部分**，超出部分的电价是交易时刻电价的 1.5 倍」⇒ 只对**差额部分**计 50 %/150 %；「总的购电费用包括计划购电费用、紧急购电费用和调整购电量的相关费用」。 |
| **小案例（可直接写进论文）** | 取 $c=1$，$P=100$：<br>· $Q=80$ ⇒ $80+0.5\times20=\mathbf{90}$；<br>· $Q=120$ ⇒ $100+1.5\times20=\mathbf{130}$。 |
| **⚠️ 另一种读法（本方案不采用，但须披露）** | 若把「计划购电费用」理解为**按 $P$ 全额支付**，则 $Q=80$ 时为 $100+0.5\times20=110$。本方案采用前一种读法（只对差额计违约费），因为它与「违约**电价**是交易时刻电价的 50 %」的字面含义一致，且与附件 5 模板的费用科目划分一致。**论文应写明该读法。** |
| **结算次数与退款假设** | ① 相对 $P$ **一次性**结算，不按节点增量逐次结算；② 不引入跨日结转、不做多次退款；③ 紧急购电 $b$ 单独按 $5c$ 计，不参与 $P/Q$ 的违约/加价机制。 |
| **论文写法** | 「计划量 $P$ 于 0:00 确定且不可撤销；全天按最终兑现量 $Q$ **一次性**结算：低于计划的部分按 0.5 倍电价计违约费、高于计划的部分按 1.5 倍电价计加价费，紧急购电按 5 倍电价单列。例：$c=1,P=100$ 时 $Q=80\to90$、$Q=120\to130$。」 |

## A-6　执行器附加限制：紧急购电时段**不主动充电**

| 项 | 内容 |
|---|---|
| **假设** | 执行器按**缺额 / 富余**分支处理：缺额时段只允许「放电 + 紧急购电」，富余时段只允许「充电 + 弃电」。因此同一时段**不存在**「紧急购电 + 主动充电」。 |
| **性质** | 这是**执行器额外的工程限制**（题面**未**强制要求），目的是**不采纳**「一边按 5 倍价买电、一边把它充进电池」这一**动作组合**。⚠ 该动作组合在物理上**并非不可能**（只是会被题面按上述四项科目计价）；本文出于保守设定而不允许它，故应写成「本文附加的工程限制」，**不得**写成「非物理」「物理上不可能」。 |
| **实现依据** | `代码/_dpexec.py`：`# ---- 缺额分支：只放电 + 紧急购电 ----` / `# ---- 富余分支：只充电 + 弃电 ----`；`b` 与 `C` 分别只在与 `pos` 同/异的时段取值。 |
| **影响范围** | 不改变题面结算口径（B 合同的四项科目不变），只影响执行层动作的组合方式；验证套件 `C1`（含 $b$ 的能量平衡）、`C3`（界）、`C4`（同段充放互斥 $C\cdot D=0$）均在全年 334 日上通过。 |
| **论文写法** | 「执行层按缺额/富余分支执行：缺额时段只放电并紧急购电，富余时段只充电并消纳弃电；即禁止以紧急购电为电源主动充电（本文附加的工程限制，该动作组合并非物理上不可能，仅因本文保守设定而不采纳；不影响题面结算口径）。」 |

## A-7　方法命名：**因果滚动 / 情景近似策略**（不是全局最优）

| 项 | 内容 |
|---|---|
| **准确名称** | **因果滚动（rolling-horizon）+ 情景近似（scenario-based approximation）策略**；每个节点内为**两阶段**近似（当日起决策 + 情景追索）。 |
| **因果性** | 第 $d$ 天的光伏情景库只用 $[d-30,\,d-1]$ 的**已发生**历史重标定残差（逐日滚动因果窗），不含未来实测；已由扰动检验（`E0a/E0b`、`A1/A2`）双向验证。 |
| **不得声称** | ❌「全局最优」；❌「最优策略」；❌「完备的多阶段随机规划」；❌「信息价值单调递增」；❌「必须 18:00 预报」；❌「18:00 基本无用 / 价值近零」。 |
| **论文写法** | 「本文采用因果滚动 + 情景近似的滚动时域策略：每 6 小时按当期可用预报求解两阶段随机规划，得到候选调整方案并与保留方案在同一情景集、同一真实库存、同一滚动 24 h 窗口下比较后决定是否采纳；该方法为近似策略，不主张全局最优。」 |
