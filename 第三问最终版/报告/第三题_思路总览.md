## 二、口径基石：附件 3 是"未来 24 小时"预报（四重核验）

**结论**：附件 3 的列头逐字为「**预报1小时 … 预报24小时**」，即第 $k$ 列对应**整点区间 $[\tau+k-1,\tau+k)$**
（等价：元素 $k=0..23$ ↔ $[\tau+k,\tau+k+1)$）；整条记录覆盖 $[\tau,\tau+24)$；夜间小时显式填 0。

**原始文件**：1461 行 × 26 列 = 1 表头 + 365 天 × 4 时刻；`日期` 列是**合并单元格**（需 `ffill`），格式 `2025-1-1`。

四条证据：

**① 列头原文（最直接）**：`预报1小时 | 预报2小时 | … | 预报24小时` —— 出题人直接给出语义。

**② 日出日落阶梯（最强）**：把 4 个 $\tau$ 的"列非零天数"折算成**绝对小时**后，**四者完全一致**：

| $\tau$ | 绝对小时窗口（数字 = 该小时在年内非零的天数） |
|---|---|
| 0:00 | h0–h3: **0** → h4: 20 → h5: 182 → h6: 345 → h7–h16: 365 → h17: 345 → h18: 182 → h19: 20 → h20–h23: **0** |
| 6:00 | h6: 345 → h7–h16: 365 → … → h19: 20 → h20–h23: **0** → \*次日 h4: 20 → \*次日 h5: 181 |
| 12:00 | h12–h15: 365 → h16: 345 → h17: 182 → h18: 20 → h19: **0** → … → \*次日 h5: 182 → \*次日 h6: 345 → \*次日 h7…: 365 |
| 18:00 | h18: 20 → h19–h23: **0** → \*次日 h0–h3: **0** → \*次日 h4: 20 → \*次日 h5: 182 → \*次日 h6: 345 → \*次日 h7…: 365 |

四个 $\tau$ 折算到绝对小时后**完全一致**，都落在全年日照窗口 $\approx[5{:}00,19{:}00)$。
这是**与天气无关的结构性规律**，只有"列 $k$ ↔ 绝对小时 $\tau+k-1$"这一种对齐才能出现。

**③ 平移扫描**（相对 MAE，位移 $d$ 个小时）：

| $\tau$ | $d=-3$ | $d=-2$ | $d=-1$ | $\mathbf{d=0}$ ✅ | $d=+1$ |
|---|---|---|---|---|---|
| 0:00 | 90.35 % | 65.73 % | 40.08 % | **14.73 %** | 18.50 % |
| 6:00 | 90.32 % | 65.48 % | 39.52 % | **12.98 %** | 17.13 % |
| 12:00 | 88.77 % | 64.79 % | 40.51 % | **16.54 %** | 21.19 % |
| 18:00 | 90.31 % | 66.16 % | 41.08 % | **17.02 %** | 20.50 % |

**④ 单日样例**（2025-06-15 的 0:00 预报，kW）：预报第 6 个值 1120 ↔ 实际 [5:00,6:00) 的 622 ✅；
若按"晚一小时"读则对应实际 [4:00,5:00) 的 2 ✗。

**附加体检**：365 天 × 4 时刻 = **1460 行中无任何全零行**（0/1460）；
全年体积 19.77–20.17 M kWh，与附件 2 实际光伏 20.25 M kWh 同量级（偏差 −1.17 % / −0.38 % / −1.63 % / −2.36 %）。

> **论文必写**：夜间为 0 是**物理事实**（无光照），不是数据缺失、更不是"预报退化"。

## 三、模型：滚动时域随机规划（每天 4 层）

### 3.1 时间与信息纪律

- $\tau\in\{0,6,12,18\}$，对应时段索引 $k_0=6\tau\in\{0,36,72,108\}$；$t=1..144$（10 min，标签为区间终点），$\Delta t=1/6$ h。
- **信息集** $\mathcal F_\tau$ = {附件 3 的 $(d,\tau)$ 预报} ∪ {[0,τ) 的**真实**出力} ∪ {历史}。
- **冻结规则**：$\tau$ 处的调整只允许改 $t>k_0$；$t\le k_0$ 已执行量冻结；起点用**真实**储电量。
- ⛔ 附件 2 的实际光伏**只进结算、不进规划**。

### 3.2 阶段 0（0:00）：两阶段随机规划 → 计划购电量 $p$

第一阶段 $p_t\ge0$（全情景共享、全天锁定）；第二阶段每情景 $q_{t,\omega},u_{t,\omega},v_{t,\omega},b_{t,\omega},C,D,E,U$。

$$\min\ \sum_t c_tp_t-\frac1M\sum_\omega\sum_t 0.5c_tu_{t,\omega}+\frac1M\sum_\omega\sum_t 1.5c_tv_{t,\omega}
+\frac1M\sum_\omega\Big[\sum_t 5c_tb_{t,\omega}-\nu E_{T,\omega}\Big]$$

$$q_{t,\omega}=p_t+u_{t,\omega}-v_{t,\omega},\quad 0\le u_{t,\omega}\le p_t,\quad v_{t,\omega}\ge0$$
$$q_{t,\omega}+b_{t,\omega}+V_{t,\omega}+D_{t,\omega}=L_{t,\omega}+C_{t,\omega}+U_{t,\omega}$$

- 等价闭式：$c_tq_t+0.5c_t|p_t-q_t|=\underbrace{c_t\min(p,q)}_{计划购电费用}+\underbrace{0.5c_t(p-q)^+}_{下调违约}+\underbrace{1.5c_t(q-p)^+}_{上调加价}$，与题面三段式**完全对齐**。
- $u\cdot v=0$ 由 LP 自动保证，**不需要 0-1 变量**。

### 3.3 阶段 $\tau\in\{6,12,18\}$：滚动调整 → 调整购电量 $q$

$p$ 已锁定为常数，只解 $t>k_0$：

$$\min\ -\frac1M\sum_\omega\sum_{t>k_0}0.5c_tu_{t,\omega}+\frac1M\sum_\omega\sum_{t>k_0}1.5c_tv_{t,\omega}
+\frac1M\sum_\omega\Big[\sum_{t>k_0}5c_tb_{t,\omega}-\nu E_{T,\omega}\Big]$$

- **变体 A**：视界截到 24:00（主结果）。
- **变体 B**：视界延伸到 $\tau+24$ h，尾段用同样的嵌套两阶段结构定价（**18:00 必须用此变体**才能被公平评价）。

### 3.4 阶段内执行器

复用第二问 **DP 未来价值执行器**（截断到 36 时段），终端值接下一阶段价值函数；
输出动态**经济保留水平** $R_t$，执行 $D_t=\min\{[r_t]^+,S,\eta[E_{t-1}-R_t]\}$。

### 3.5 结算（真实费用）

$$K_d=\sum_t c_tq_t+0.5\sum_t c_t|p_t-q_t|+\sum_t 5c_tb_t$$

规划里的 $-\nu E_T$ **不进账单**，只作规划信号。

## 四、两个理论亮点（论文加分点）

### 亮点 1：计划量的分位数从 80 % 降到 50 %

- 第二阶段可自由选 $q$ ⇒ $p$ 只通过 $0.5c|p-Q|$ 影响费用（$Q$ = 该时段最终最优购电量）。
- $\min_p\mathbb E[0.5c|p-Q|]\Rightarrow \boxed{p^*=\mathrm{median}(Q)}$。
- **机制**：调整机制把"欠购惩罚"从 $4c$（第二问：紧急购电 $5c$ vs 计划价 $c$）降到 $0.5c$，
  同时把"过购惩罚"从 $0$ 升到 $0.5c$ —— **两侧对称** ⇒ 分位数从 **80 % → 50 %**。
- **可检验推论**：第三问的计划购电量应**系统性低于**第二问。

### 亮点 2：调整费的期望规模有闭式，量级 ≈ 150 万元

$$\mathbb E[\text{调整费}]=\sum_t 0.5c_t\cdot\mathrm{MAD}(Q_t)$$
$$\approx 0.5\times0.7662\times490.65\ \text{kW}\times\tfrac16\ \text{h}\times144\times334
\approx \mathbf{1.51\times10^{6}\ \text{元}}\;\;(=\text{第二问总费用的}\approx10.6\%)$$

⇒ 调整费不是小项：**漏掉 0:00 的内生对冲、或用增量口径重复计费，都会改变全年结论**。

## 五、题面末句的直接答案（消融实验 + 已实测的先验证据）

**理论前提**：调整机制允许"不用新预报"（取 $q=p$，调整费 0）⇒ **费用关于预报集合单调不增**，
所以问题不是"要不要"（符号必 ≥ 0），而是"**值多少**"。

**实测证据 ①：各发布时刻预报精度**（8760 个整点样本）

| $\tau$ | 体积偏差 | MAE | 相对 MAE |
|---|---|---|---|
| 0:00 | −1.17 % | 340.57 kW | 14.73 % |
| 6:00 | −0.38 % | 299.96 kW | 12.98 % |
| 12:00 | −1.63 % | 382.45 kW | 16.54 % |
| 18:00 | −2.36 % | 393.56 kW | 17.02 % |

**实测证据 ②：滚动更新的精度增益**（同一时段用不同发布时刻的预报）

| 统计时段 | 0:00 预报 | 6:00 预报 | 12:00 预报 | 18:00 预报 | 相对 0:00 |
|---|---|---|---|---|---|
| $[6{:}00,24{:}00)$ | 442.17 kW | **387.98 kW** | — | — | **−12.25 %** |
| $[12{:}00,24{:}00)$ | 350.49 kW | 304.92 kW | **272.03 kW** | — | **−22.39 %** |
| $[18{:}00,24{:}00)$ | 17.77 kW | 17.77 kW | 17.77 kW | 17.77 kW | **−0.01 %** |

**实测证据 ③：18:00 预报的视界构成** —— 当日剩余 6 h（25 %，**几乎全为夜间**）/ 次日 18 h（75 %）。
量化：该窗口 365 天中仅 **20 天**在 $[18{:}00,19{:}00)$ 有微弱残留（最大 1316.9 kW，夏季日落晚），
其余恒为 0 ⇒ 预报误差仅 17.77 kW，且**四个发布时刻在该窗口的误差完全相同**。

**结论**

| 档 | 参与调整的时刻 | 预期价值 |
|---|---|---|
| $S_0$ | 无（$q\equiv p$） | 基线 |
| $S_{06}$ | {6:00} | **正、显著** |
| $S_{0612}$ | {6:00, 12:00} | **最大，推荐** |
| $S_{061218}$ | {6:00, 12:00, 18:00} | 相对 $S_{0612}$ 增量 **≈ 0** |
| $S_{all+}$ | 上述 + 跨日展望尾 | 给 18:00 最后一次机会，仍预期极小 |
| $PF$ | 完美信息（附件 2 实际光伏） | 下界 |

**叙事**：18:00 的预报"对今天"几乎零信息（今日剩余 6 h 中仅 20 天在 [18:00,19:00) 有微弱残留，
其余恒为 0；四个发布时刻在该窗口的 MAE 都是 17.77 kW）；"对明天"的信息被**次日 0:00 的更优预报支配**；
唯一残余通路是"今夜 22:00–24:00 低价（0.4182–0.4249）为明天预充电"，
而该价格与次日凌晨（0.4265–0.4394）几乎相同，套利空间被储能容量/功率夹得很小。
⇒ **建议引入 6:00 与 12:00；18:00 保留但预期收益极小**（须由消融实验坐实）。

## 六、其他关键实测结论

1. **整点→10 min 展开口径**：分段常数 MAE **171.05 kW** / RMSE 295.40 kW；
   线性插值（常见参考给法）MAE 276.02 kW / RMSE 424.19 kW ⇒ **推荐分段常数**。
2. **误差预算**（0:00 预报 + 因果负荷预测，2025 全年）：负荷 MAE 202.67 kW、
   光伏 MAE **371.86 kW**、净负荷 MAE 490.65 kW（相消检查通过：490.65 < 202.67+371.86）。
   ⚠️ 附件 3 的预报精度**低于**第二问自造的"前 7 天均值"（153.4 kW）——第三问紧急购电量**会更大**，
   论文需显式解释这个反直觉现象。
3. **附件 4 边界**：附件 4 的全年逐时段均值 = 附件 1 电价曲线（最大差 5.2×10⁻⁵、相关 1.0000），
   ∈[0.0076,1.7936]，日内峰谷比 5.85。**第三问严禁使用附件 4**。
4. **电价结构**：谷 $[0{:}00,5{:}00)$ ≈ 0.43、$[22{:}00,24{:}00)$ 0.418–0.425；
   峰 $[18{:}00,21{:}00)$ 最高 1.3483、$[8{:}00,9{:}00)$ 1.0815；
   $[11{:}00,13{:}00)$ 存在光伏压低的**中午电价凹陷**（0.4729/0.5250）。峰谷比 3.22。
