## 1. 策略名称与定位（必须照此措辞）

本文第三问的求解策略统称 **「因果滚动近似策略」**：

* 在每个调整节点 τ∈{0,6,12,18}，把**该时刻已发布**的第三方预报展开为
  当日剩余时段与（若已发布）次日对应时段的**条件情景集**；
* 在同一情景集上用两阶段随机规划（`mode='adjust'`）给出**调整购电计划候选**；
* 用**条件期望总费用**在实际执行器意义下比较「维持旧计划」与各候选，采纳更优者；
* 按本节点最终选定的计划（维持旧计划或采纳新计划）重建**保留水平（价值函数）**，并用阶段内 DP 执行器实际执行。

**允许的说法**：滚动、因果、条件期望、近似策略、「在同条件反事实下比较」。
**禁止的说法**：全局最优、最优策略、完备随机规划、「信息价值单调递增」、「必须 18:00 预报」、「18:00 基本无用 / 价值近零」、「继承 1 月的真实运行末态」。

1. **不得写「正式计划量 = 中位数」**。正式入口 `stage0_mode='plan'` 在 0:00

## 3. 口径与边界（论文必须写明）

* **结算口径（B）**：`Σ c·min(P,Q) + 0.5·Σ c(P−Q)⁺ + 1.5·Σ c(Q−P)⁺ + 5·Σ c·b`；其中 `P` 为日前申报量、`Q` 为调整后兑现货量、`b` 为紧急购电量。
* **能量平衡必须含紧急购电**：`Q + b + D − C − N − 弃电 = 0`（逐时段，本轮实测最大偏差见验证套件）。
* **评分期**：2025-02-01 → 2025-12-31，共 334 天；2025 年 1 月**仅用于标定**（情景构造、残差因子等），评分期内库存**连续递推**，
  不使用「1 月真实运行末态」之类的外部信息。
* **终端价值**：`ν·E_T` 只用于**计划层**的滚动评价；不同策略的账单比较
  同时给出库存中性可比费用，避免「靠清空库存省钱」的伪结论。
* **滚动窗口**：每个节点 τ 的「候选规划 → 新旧比较 → DP 价值构造」统一覆盖 [τ, τ+24h)，窗口段数 ≡ 144  段；**本日已申报量不可撤销**，故窗口的前若干段只影响
  后续决策与价值函数，不改变已申报量。
* **次日 0:00..τ−1 的采购量**是本节点的一阶段共享变量：候选规划与接受检验使用**同一个** `q_next`（跨日一致），不引入「规划时用一套、比较时用另一套」的口径错配。
* **三个发布统计彼此独立**：`购电量被采纳`（采购计划真的被改）、`价值函数被更新`（保留水平按本节点最终选定的计划重建）、`预报发布被使用`（该节点已发布的预报参与了本次决策）。三者不可互相替代。

## 4. 保留的近似与未做项（如实披露）

* 单节点内仍为**两阶段**近似：当日起决策 + 情景追索，非完整情景树 / 多阶段随机规划 / CVaR / 全局最优对照。
* 情景数 M = 30、库存网格步长 δ = 6 kWh；参数加密实验显示主指标变化在 0.5 % 量级内，但紧急电量等分项**尚未收敛**（不得声称已收敛）。
* 次日展望所需的「次日 0..τ−1」预报片段取自附件 3 在该节点已发布的部分，其残差因子沿用「同小时代理」标定；本修复**不改动**该标定，只补齐其使用。
* 本轮**不做**：完整情景树、多阶段随机规划、CVaR、大规模敏感性扫描、精确最优对照、预测组合、条件情景更新、`M=50`。

**结论边界（必须与结论一起写进论文）**：

0. **这是三方案顺序差额比较，不是严格识别出的两种独立因果贡献**：只存在三组（`N0` / `F061218` / `N061218`），并不存在完整的四格2×2（未做「不允许重优化但允许新预报」那一格）；且 `N0` 本身既无日内重优化、也无跨日展望与 0:00 冻结外推。故 `202,602.21 + 56,172.98 = 258,775.19` 是正确的**沿这三种方案进行的差额分解**，但不得写成「已严格识别的两项因果贡献」。
1. 本对照拆开的是**通道**，不是「信息价值」的**完备度量**：`F061218` 在 6/12/18 仍会决策（仍读**自己的**真实 SOC），故 `N0 − F061218` 是「多三次重优化机会」的价值，而非「再多买一份预测」的价值。
2. 冻结组在 0:00 对**次日**的不确定时段使用了**因果外推**（附件 3 在 0:00 对次日无任何输出；不用外推则 24 h 窗口无法保持可比）。该外推只使用已发生的 `pv_h[:d]`。因此**上述两段差额都包含外推方法的影响**，其大小依赖外推方法与近似执行策略；方向不作任何预设，外推使冻结组基线变好或变差都如实报告（若变差，反而会放大正式方案的相对优势，故不能以「方向上不利于结论」为由声称不构成夸大）。
3. 仍**不是**完整多阶段随机意义上的全局最优对照：单节点内仍是两阶段近似；未做完整情景树 / MSP / CVaR；未做预测器重建与单调排序调参。
4. **行为不是调参目标**：「账单随节点增多单调下降」是本轮全年回测的**实测结果**，不是模型的正确性判据，也不是优化目标。
5. **终端库存仍不同**，故两口径（账单 / 库存中性可比费用）必须同时报告（ν = 0.4815481481）。
6. 冻结组读**自己的**真实 SOC 轨迹（不复制正式组 SOC、不反向对齐末态）。
7. 冻结组的「预报发布被使用（次）」= **0** 是**字段定义**使然（它不使用该节点相对 0:00 的新增发布），**不代表冻结失效**；其「价值函数被更新（次）」仍 = 调整节点数。
